# Rangkaian-DOL-Starter
Repositori ini berisi materi pembelajaran, dokumentasi, dan file simulasi untuk Praktikum Mesin-Mesin Listrik. Materi ini berfokus pada pemahaman sistem kendali elektromagnetik, perancangan rangkaian Direct On Line (DOL) Starter, serta pengujian simulasi menggunakan perangkat lunak CADe_SIMU.
